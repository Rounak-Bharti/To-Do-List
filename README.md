# TaskFlow — To-Do List App

A clean, responsive task management web application built using **HTML, CSS, and JavaScript**. TaskFlow helps users organize daily tasks, track their progress, and manage completed and pending tasks.

 🌐 Live Demo

[Open TaskFlow](https://rounak-bharti.github.io/To-Do-List/)

✨ Features

- **Add Tasks:** Create tasks with a title and an optional note.
- **Mark as Completed:** Mark tasks as complete when finished.
- **Delete Tasks:** Remove tasks you no longer need.
- **Task Filtering:** View all, pending, or completed tasks.
- **Progress Tracking:** Track completed tasks and overall progress.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Use the application on desktop and mobile devices.

 🛠️ Technologies Used

- HTML5 — Application structure
- CSS3 — Styling and responsive layout
- JavaScript — Task functionality and DOM manipulation
- Local Storage — Persistent browser-side data storage
- GitHub Pages — Website hosting

🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Rounak-Bharti/CodeOrbit_ToDoList.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.

💾 Data Storage

TaskFlow uses the browser's `localStorage` to save tasks. Data is stored locally in the browser and does not automatically synchronize across different devices or browsers.

This project demonstrates practical frontend development skills, including responsive web design, JavaScript DOM manipulation, event handling, and browser-based data persistence.
